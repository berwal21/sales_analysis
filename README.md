# Sales Data Analysis Using Python

## Project Overview
This project analyzes sales transaction data using Python to identify revenue trends, product performance, category contribution, and city-wise sales performance.

## Tools & Technologies
- Python
- Pandas
- Matplotlib
- CSV data

## Business Questions
- What is the total revenue and average order value?
- Which product generates the highest revenue?
- Which city contributes the most revenue?
- Which month has the highest and lowest revenue?
- Which product sells the most units?
- What percentage of revenue comes from Electronics?

## Key Findings
- **Total Revenue:** ₹569,000
- **Total Orders:** 15
- **Average Order Value:** ₹37,933.33
- **Top Revenue Product:** Laptop
- **Top Revenue City:** Rohtak
- **Best Sales Month:** March
- **Lowest Sales Month:** May
- **Most Units Sold:** Mouse (23 units)
- **Electronics Revenue Contribution:** 94.55%

## Data Analysis Process
1. Loaded the CSV dataset using Pandas.
2. Checked for missing values and duplicate records.
3. Calculated revenue using quantity multiplied by price.
4. Analyzed revenue by product, category, city, and month.
5. Calculated average order value, revenue contribution, and monthly growth.
6. Created visualizations using Matplotlib.
7. Exported summary reports for further analysis.
   
## How to Run
1. Install Python.
2. Install the required libraries:
   ```bash
   python -m pip install pandas matplotlib
   ```
3. Place `sales_analysis.py` and `sales_data.csv` in the same folder.
